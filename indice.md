# Trabajo Práctico GIT

## Introducción
Nosotras, integrantes del grupo 26, creamos este repositorio para presentarlo como la resolución del trabajo practico.

Durante el desarrollo, nos enfocamos en el uso de ramas independientes para cada tarea, el debate e interacción del equipo mediante comentarios en los Pull Requests, y el uso de la convención de *Conventional Commits* para mantener un historial de cambios profesional, claro y trazable.

## Índice del Repositorio
A continuacion, presentamos los accesos directos a cada una de las secciones que componen este trabajo practico:

### 1. Documentación de Comandos de Git
Explicaciones redactadas con nuestras palabras sobre los comandos explicados durante la cursada:

* [Comandos Básicos de Git](comandos/basicos.md): Detallamos el paso a paso para arrancar un proyecto desde cero, clonarlo, ver los estados de los archivos, guardar los cambios en local y subirlos a github (`git init`, `git clone`, `git status`, `git add`, `git commit` y `git push`).
* [Comandos Avanzados de Git](comandos/avanzados.md): Explicamos como manejamos las ramas en el grupo, cómo unimos el código, el orden del historial, cómo volver atrás si cometimos un error y el guardado temporal (`git branch`, `git checkout/switch`, `git merge`, `git remote`, `git fetch`, `git pull` y `git stash`).

### 2. Métricas del Proyecto
* [Estadísticas del Repositorio](estadisticas.md): En esta sección armamos un informe real del proyecto. Contiene cuantos commits aportó cada integrante, la cantidad de merges que realizamos, el total de ramas creadas y los comandos de consola que utilizamos para sacar esos datos.

### 3. Uso de Herramientas de Asistencia
* [Uso de Inteligencia Artificial (IA)](IA.md): Documento obligatorio donde explicamos como usamos los modelos de inteligencia artificial para ayudarnos a aclarar dudas durante la resolucion.
